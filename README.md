# Duelstock on Vercel

Deploy the contents of this directory as a Vercel project with the Other framework preset. The included vercel.json serves the public directory without a build step. With an authenticated Vercel CLI, run `vercel --prod` from this directory.

Inventory is stored in each browser. To move data from the older site, download a backup on the old site and import it into the empty workspace on the new site. The import preserves the existing workspace if it already has records. The site has no app-level accounts or cross-device sync.

Use Edit on an inventory row to correct details or quantity. Open a recorded order and select Reverse sale to void it, with the option to return the cards to their original batches.

## Faster intake and order entry

Use Save and add next for a run of cards in the same bin and language. Duplicate on an inventory row prefills card details for a new batch. Enter its purchase cost and quantity before saving. Search each order line by card name, set code, edition, or bin before selecting the specific batch.
